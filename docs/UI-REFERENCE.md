# Referencia visual (vídeo Gemini)

El mockup de 10 s que hay que copiar:

- Splash: logo hexagonal CloudTerm, texto **Tu equipo de terminales está listo**, escena pixel de escritorios.
- App: fondo #0B1214, acento #40E0D0, pestañas de sesión (xterm.js, prod-web-01…), editor oscuro, barra inferior **Home / Servers / Terminal / Agents / Settings**.
- Command Palette tipo VS Code.
- Toast de conexión + barra de progreso mint.

## Cómo subir el vídeo al repo

GitHub no deja empujar el MP4 (3 MB) por la API de texto. Súbelo a mano:

1. En GitHub → `feat/pixel-agents` → **Add file** → **Upload files**.
2. Sube `cloudterm-ui-reference.mp4` a `docs/`.
3. Commit en la misma rama.

El archivo original del chat se llama `gemini_generated_video_044c8a30.mp4`.
